# Lektion 16

## Repetition
Vi kommer att gå igenom vad vi hittills har lärt oss om Cross Plattform Desktop utveckling med Avalonia.

1. I terminalen skapa en katalog/mapp RunStore.
2. Navigera in i katalogen.
3. Skriv in följande kommando `dotnet new sln` och tryck _Enter_.
4. Öppna VS Code `code .`,
5. I VS Code öppna den interna terminalen.
6. Skriv in följande kommando för att skapa en Avalonia Applikation `dotnet new avalonia.app -n Client` och tryck _Enter_.
7. I terminalen ange nu följande kommando `dotnet sln add Client` och tryck _Enter_.
8. Installera communitytoolkit.mvvm via Nuget i Client projektet.
9. Fortfarande i terminalen navigera in i Client projektet.
10. Skapa följande kataloger med kommandot `mkdir Views ViewModels`.
